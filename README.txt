CELL QR TEAM V4 — без аккаунтов и паролей.
1. В Supabase SQL Editor выполнить PUBLIC_ACCESS.sql.
2. В config.js один раз вставить только публичный sb_publishable_ ключ Supabase. Адрес проекта уже указан.
3. Загрузить файлы (кроме README.txt и PUBLIC_ACCESS.sql) в корень GitHub Pages.
4. Обновить PWA/страницу после публикации.
РИСК: любой, у кого есть ссылка/публичный ключ, сможет просматривать и изменять складские ячейки. Настоящего разграничения прав, журнала сотрудников и защиты от спама нет.
