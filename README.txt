CELL QR — обновление V8 «Обход хранения»

КАК ОБНОВИТЬ НА GITHUB
1. Открой репозиторий с вашим QR-приложением и папку, в которой лежит index.html.
2. Распакуй архив. Загрузи туда 5 файлов: index.html, team.js, sw.js, walk.js, walk.css.
   На GitHub: Add file → Upload files → перетащи эти пять файлов → Commit changes.
3. Дождись завершения публикации GitHub Pages.
4. Открой приложение в Safari и обнови страницу. Появится вкладка «Обход».
   Если приложение добавлено на домашний экран, полностью закрой его и открой снова после обновления в Safari.

ВАЖНО: это готовое ОБНОВЛЕНИЕ существующего приложения.
Не удаляй остальные файлы репозитория. config.js, qr-engine.js, manifest.webmanifest,
иконки и настройки GitHub Pages остаются вашими. SQL для этого обновления не нужен.
Если впервые настраиваете базу, прежняя настройка приложения выполняется отдельно.

ОБХОД
• K09 и K10: ряды 01–50, этажи 1–5, секции A/B/C.
• K02: ряды 01–25, этажи 1–5, секции A/B/C.
• AS6: ряды 06–24, этажи 1–6, секции A/B/C.
• Выбирай зону, прокручивай ряды и отмечай свободные ячейки. Зеленая — отмечена.
  Серая — не отмечена; это не проверенный статус занятости.
• Повторное нажатие снимает отметку. К ряду — быстрый переход по номеру.
• Этажи сверху вниз: от верхнего к первому.
• Скопировать — выписка ВСЕХ зон. Совпадающие этажи объединяются: A4 и C4 → AC4.
  Порядок: K09, K10, K02, AS6; ряды и этажи по возрастанию.
• Новый обход — очистка отметок всех зон на этом устройстве после подтверждения.
• Сохранение работает в этом браузере на этом телефоне. Оно не синхронизируется
  с другими устройствами и не меняет общую базу вкладки «Свободные».
  Для обхода используй одну вкладку. При очистке данных браузера отметки удалятся.
• Вставляй скопированный текст в ваш чат вручную.
• После первого успешного открытия обновленной версии обход доступен без сети.
